# Platform proof stream

- `environment.json` is regenerated by `tools/phase0/probe-environment.sh` and
  intentionally omits personal device/certificate identifiers.
- `external-status.json` distinguishes locally discovered prerequisites from
  blocked Apple/target/device behavior.
- `background-download-procedure.md` defines the future executable real-device
  proof without claiming it ran.
- `carplay-entitlement.md` records the exact unmanaged external state.

Real-device evidence must never be replaced with a simulator-only result.
